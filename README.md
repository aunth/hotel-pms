# Hotel PMS

Система управління готельним комплексом (property management system) для готелю на 50–150 номерів. Навчальний наскрізний проєкт з дисципліни «Технології розроблення програмних систем», варіант 12.

## Призначення

Замінює набір таблиць Excel, паперовий журнал прибирання та окремі кабінети онлайн-сервісів єдиною системою, у якій немає розбіжностей між каналами бронювання.

## Функціональність

- F1 – облік номерного фонду і тарифів
- F2 – бронювання (у тому числі з Booking.com та Airbnb через channel manager)
- F3 – реєстрація заїзду та виїзду
- F4 – база гостей (CRM)
- F5 – рахунки, оплата та фіскалізація
- F6 – управління прибиранням (housekeeping)
- F7 – управлінська звітність

У цьому репозиторії реалізовано лише невелику частину ядра (предметна модель і пошук вільних номерів), щоб на ній відпрацьовувати роботу з Git.

## Технології

- TypeScript (Node.js 24, запуск без збирання)
- PostgreSQL 16 (у плані, у репозиторії поки немає)
- Вбудований тестовий запуск `node --test`
- GitHub Actions для перевірок

## Запуск

```bash
npm test          # запустити тести
npm run check     # перевірити структуру репозиторію
```

## Структура

```
docs/    документація (SRS, ADR)
src/     вихідний код
tests/   автоматичні тести
```
